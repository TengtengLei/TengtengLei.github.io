# 图片文件夹

把下面这些文件放进这个文件夹：

| 文件名 | 用途 | 建议规格 |
|---|---|---|
| `profile.jpg` | 首页头像 | 正方形，600×600 像素以上，JPG，小于 500 KB |
| `favicon.svg` | 浏览器标签页小图标 | 已有一个占位版本，想换字母就用记事本打开改里面的 `L` |

**照片压缩**：手机拍的照片通常 3–5 MB，会让网页加载很慢。
上传前用 <https://squoosh.app> 压到 300 KB 以内（免费，在浏览器里跑，不上传服务器）。

其他图片（研究示意图、课程配图等）也放这里，在 `content.js` 里用
`assets/img/文件名.jpg` 引用。
